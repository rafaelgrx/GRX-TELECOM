Relatório de validação

GRX Telecom · versão 2.0 · revisão de 02/11/2026

98 verificações automatizadas aprovadas na rodada final. São verificações delimitadas, não uma certificação de ausência absoluta de defeitos.

Limites de validação: nenhum projeto Supabase de produção foi acessado. Os testes de integração usam o SDK real com HTTP simulado; o SQL foi executado em PostgreSQL WASM com schemas auth/storage simulados. WebKit encerrou ao iniciar neste ambiente: Safari/iPhone não foi homologado. Nenhum aparelho Android ou iOS físico foi usado.

Escopo e metodologia

Aplicativo revisado a partir de Appgrx.html, preservando identidade visual, cadastros padrão, categorias e e-mail de administração. Layout verificado nas quatro seções em larguras de 320, 360, 390, 768, 1024, 1440 e 1920 px. Os testes de acessibilidade usam axe-core e não substituem auditoria manual com leitores de tela. As fotos de teste e os lançamentos demonstrativos não são dados reais.

Não homologado nesta entrega

Login, upload, refresh de tokens e sincronização contra o projeto Supabase real; entrega de e-mails de recuperação; comportamento em Safari/iOS e celulares físicos; múltiplos usuários concorrentes em produção; migração de uma base real preexistente; volume de milhares de fotos; recuperação de dispositivo fisicamente perdido. Os arquivos de SQL e teste estão incluídos para revisão e homologação.
